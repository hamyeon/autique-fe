# HomeHeader

홈 탭 상단의 60px 헤더로, 왼쪽에 Autique 로고(108×28)를, 오른쪽에 검색 · 알림 · 장바구니 아이콘을 16px 간격으로 둡니다.

- 로고는 Figma `img_logo` 원본 SVG입니다(검은 워드마크 + `primary1` 점). 다른 화면에서는 로고 대신 Header를 씁니다.
- 좌우 여백 20px, 하단 1px `gray2` 선. 넓은 기기에서도 로고는 왼쪽, 아이콘 묶음은 오른쪽 끝에 붙습니다.
- 소비 측이 제공: `onSearch`, `onNotifications`, `onBag`.
