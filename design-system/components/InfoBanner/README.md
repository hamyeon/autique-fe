# InfoBanner

놓치면 안 되는 조건·결과를 알려주는 박스로, 18px 정보 아이콘과 caption02 본문(`gray6`)을 12px 패딩 안에 둡니다.

| tone | 모양 | 쓰는 곳 (Figma `tone`) |
| --- | --- | --- |
| `default` | `gray1` 배경, 파란 정보 아이콘, 테두리 없음 | 규칙·안내: 자동 입찰 방식, 최소 입찰 단위 |
| `error` | `error4` 배경, `error2` 테두리, 빨간 정보 아이콘 | 경고·결과 통보: 낙찰 취소, 결제 기한 |

- 요약 카드 바로 아래나 바텀시트 제목 아래에 둡니다. 한 화면에 하나.
- 문장은 해요체 한두 문장("~할 수 있어요", "~해 주세요"). 무엇이 일어나는지 + 그 결과를 순서대로.
- 소비 측이 제공: `tone`, 본문 텍스트(children).
