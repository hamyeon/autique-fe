# Tag

흰 바탕 아웃라인 태그로, 4 · 8 패딩과 `radius-sm` 모서리를 씁니다(Figma Tag).

- `size="md"`(caption02): 카드 머리의 AI 태그(AI 적정 시세, AI 적정 기준가).
- `size="sm"`(label01): 상태 배지(최고 입찰자 · 나, 상한가 초과).
- `tone="primary"`: `primary2` 테두리 · `primary1` 글자, 나와 AI 관련. `tone="error"`: `error2` · `error1`, 초과·위험.
- 채워진 상태 라벨(경매 예정, LIVE, 최고가)은 Chip을 써요.
